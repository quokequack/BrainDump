SQL Developer Data Modeler

1. O que é?

O Oracle SQL Developer Data Modeler é uma ferramenta de modelagem que ajuda a projetar a estrutura dos bancos de dados e a gerar scripts de criação (DDL). Ela não é o banco de dados em si: o SGBD, como Oracle Database, gerencia e armazena os registros.

Antes de criar um sistema de biblioteca, por exemplo, é necessário projetar tabelas de livros, usuários e empréstimos; campos; chaves; relacionamentos e restrições.

2. Níveis da modelagem

Modelo lógico: entidades e regrasModelo relacional: tabelas, colunas e chavesModelo físico: implementação e armazenamento

O modelo lógico representa os conceitos do negócio; o relacional os transforma em relações (tabelas); o físico considera características concretas do SGBD e do armazenamento.

3. Schema, owner e objetos

O schema organiza objetos associados a um proprietário (owner). No Data Modeler é possível criar o esquema, informar seu nome e associar objetos como tabelas, índices e views.

ObjetoFunção
TabelaArmazena registros
ÍndiceAuxilia a busca/acesso aos registros
ViewRepresenta uma consulta armazenada como objeto
SchemaAgrupa e identifica objetos de um proprietário

4. Configurações do Data Modeler

  • Versão do RDBMS: define a versão de referência para o modelo.
  • Nulos permitidos: quando selecionado na preferência descrita no slide, novas colunas começam como não obrigatórias.
  • Direção das setas de FK: o material sugere da chave primária para a estrangeira; é uma configuração visual.
  • Índices para FK: a ferramenta permite configurar sua geração, sem confundir índice e restrição.
  • Tipos de dados: podem ser administrados, alterados, eliminados e marcados como preferidos.
  • Domínios: definições reutilizáveis para padronizar tipos de colunas, também com opção de preferidos.
  • Nomenclatura: padrões consistentes para nomes dos objetos.

5. Tipos de dados, domínio e restrições

ItemSignificado
VARCHAR2(100)Texto de até 100 caracteres, conforme semântica configurada
NUMBER(10,2)Número com precisão de 10 dígitos e escala de 2

CREATE TABLE Cliente (
  id NUMBER PRIMARY KEY,
  nome VARCHAR2(100) NOT NULL,
  email VARCHAR2(150) UNIQUE
);
CREATE TABLE Pedido (
  id NUMBER PRIMARY KEY,
  cliente_id NUMBER NOT NULL,
  valor NUMBER(10,2) CHECK (valor >= 0),
  CONSTRAINT fk_cliente_pedido
    FOREIGN KEY (cliente_id) REFERENCES Cliente(id)
);

Diferenças: a PK identifica e não se repete; a FK pode se repetir e pode ser nula se não tiver NOT NULL; a UK garante unicidade; índices são estruturas de acesso, não sinônimos de PK ou UK.

6. Convenções e recursos adicionais

O material sugere prefixos PK_, FK_, AK_, IDX_, CK_ e NN_. Exemplo: PK_CLIENTE e FK_CLIENTE_PEDIDO. São padrões recomendados, não sintaxe obrigatória.

DEFAULT indica um valor padrão para a coluna; sequence gera números; trigger executa ações automáticas em eventos; coluna calculada deriva valores de uma expressão. A ferramenta também permite scripts e comentários para documentar objetos.

7. Modelo físico: tablespace e particionamento

Tablespace é a unidade lógica de armazenamento do Oracle. Particionamento divide uma tabela em partes segundo alguma regra, por exemplo, registros por ano. Ambos aparecem nas configurações do modelo físico.

Memorize: schema organiza; tabela armazena; PK identifica; FK relaciona; CHECK valida; NOT NULL obriga; índice auxilia o acesso; tablespace organiza o armazenamento.

Metas SMART

SMART é uma metodologia para escrever metas claras e úteis à gestão. Os slides atribuem sua formulação a George T. Doran, em 1981.

LetraSignificadoPergunta
SSpecific — EspecíficaO que exatamente alcançar?
MMeasurable — MensurávelComo medir o progresso?
AAchievable — AlcançávelÉ viável com os recursos disponíveis?
RRelevant — RelevanteEstá ligada a um objetivo importante?
TTime-bound — TemporalQual é o prazo?

Meta vaga: “Melhorar as vendas”. Meta SMART: “Aumentar os pedidos mensais de 1.000 para 1.200 até 31 de dezembro, usando a equipe e o orçamento disponíveis”. A meta tem resultado, indicador, viabilidade, relevância e prazo.

Metas, métricas e KPIs

A meta é o resultado pretendido. A métrica é uma medida. Um KPI é uma métrica selecionada como indicador-chave para acompanhar um objetivo. Nem toda métrica é um KPI.

Exemplo dos slides: um e-commerce quer aumentar a taxa de conversão de 2,5% para 3,2% em 90 dias, preservando ticket médio acima de R$ 180.

Taxa de conversão = (Pedidos / Sessões) × 100%
Ticket médio = Receita / Número de pedidos

Se houver 10 mil sessões e 250 pedidos, a conversão é 2,5%. Para chegar a 3,2% com as mesmas sessões, seriam necessários 320 pedidos.

Gap: distância até a meta

De 2,5% para 3,2%, o gap é de 0,7 ponto percentual. O crescimento relativo exigido é 28%: (3,2 − 2,5) / 2,5 × 100.

SMART e análise de dados

Uma meta clara orienta quais indicadores, tabelas, dimensões, granularidade e visualizações precisam ser construídos. Dimensão é uma perspectiva, como tempo, região ou produto; granularidade é o nível de detalhe dos registros. Dashboards executivos resumem resultados; análises detalhadas ajudam a investigar as causas. O storytelling com dados compara a situação atual, a meta e o progresso.

Memorize: metas definem o resultado; KPIs acompanham o progresso; dados e dashboards apoiam decisões.

Análise Exploratória de Dados (EDA)

1. Objetivo da EDA

EDA (Exploratory Data Analysis) é uma abordagem para investigar, resumir e compreender um conjunto de dados: classificar variáveis, observar gráficos e tabelas, calcular estatísticas, avaliar qualidade (ausências/inconsistências) e elaborar hipóteses para análise futura, OLAP e machine learning.

2. Univariada, bivariada e multivariada

Univariada: uma variável, como a distribuição das notas. Bivariada: duas variáveis, como idade versus salário. Multivariada: três ou mais variáveis, podendo envolver PCA.

3. Estatística descritiva e inferencial

Descritiva sintetiza os dados observados; inferencial utiliza amostras para estimar características da população. População é o conjunto de interesse; amostra é o subconjunto estudado, que precisa ser representativo para evitar vieses.

4. Observações, variáveis e tipos

Observações são os registros (geralmente linhas); variáveis são os atributos (geralmente colunas). Variáveis qualitativas podem ser nominais (sem ordem: cor) ou ordinais (com ordem: ruim/regular/bom). Variáveis quantitativas podem ser discretas (contagens) ou contínuas (medidas).

Pegadinha: uma idade em anos pode ser quantitativa; uma faixa etária, qualitativa ordinal. Um CPF numérico é identificador, não grandeza quantitativa para análise estatística.

5. Representações dos dados

  • Tabelas: organizam frequências e cruzamentos.
  • Barras/colunas: comparam categorias.
  • Setores (pizza): proporções de um total.
  • Linhas: evolução, especialmente temporal.
  • Histograma: distribuição de variáveis quantitativas em intervalos; barras adjacentes.
  • Polígono de frequências: pontos das frequências conectados.
  • Colunas múltiplas: comparam grupos/séries.

6. Estatísticas e parâmetros

Estatística: medida calculada de amostra. Parâmetro: medida calculada de toda a população.

7. Tendência central

Para os valores 2, 4, 4, 6, 9:

  • Média: soma / quantidade = 25 / 5 = 5.
  • Mediana: valor central dos dados ordenados = 4. Com N par, calcule a média dos dois valores centrais.
  • Moda: valor mais frequente = 4. A distribuição pode não ter moda ou ter várias.
Média = Σxᵢ / n

8. Assimetria e curtose

Distribuição simétrica: caudas equilibradas; em distribuições típicas unimodais, média ≈ mediana ≈ moda. Assimetria positiva: cauda à direita, com tendência à média > mediana > moda. Assimetria negativa: cauda à esquerda, com tendência inversa. São regras didáticas, não identidades universais.

Curtose é apresentada pelos slides em termos de achatamento: mesocúrtica (referência normal), leptocúrtica (mais pontiaguda) e platicúrtica (mais achatada). Em estatística, a curtose também é fortemente relacionada ao peso das caudas.

9. Dispersão

As turmas 7,7,7,7,7 e 3,5,7,9,11 têm média 7, mas dispersões diferentes.

  • Amplitude: máximo − mínimo. Para a turma B, 11 − 3 = 8.
  • Desvio médio absoluto: média dos módulos dos desvios à média. Para B, (4+2+0+2+4)/5 = 2,4.
  • Variância populacional: média dos desvios quadráticos. Para B, (16+4+0+4+16)/5 = 8.
  • Desvio padrão populacional: raiz da variância, √8 ≈ 2,83.
Variância populacional = Σ(xᵢ − μ)² / N
Desvio padrão = √Variância

Para a variância amostral corrigida, utiliza-se n−1 no denominador. No mesmo exemplo, o resultado é 10.

10. Coeficiente de variação

CV = (desvio padrão / média) × 100%

Com média 50 e desvio padrão 5, CV = 10%. O material considera homogênea uma distribuição com CV de até 20%; esse é um critério didático contextual, não uma regra universal. O CV não é indicado quando a média está próxima de zero.

11. Quartis, decis, percentis e box plot

Quartis dividem em quatro partes; decis em dez; percentis em cem. Q1 corresponde ao P25, Q2 é a mediana/P50, e Q3 corresponde ao P75.

Box plot resume distribuição, mediana, quartis, dispersão e possíveis outliers. O intervalo interquartil é Q3 − Q1. Uma regra comum identifica candidatos a outliers fora de [Q1 − 1,5 × IQR, Q3 + 1,5 × IQR]. Outliers podem ser erros ou ocorrências legítimas: não devem ser excluídos automaticamente.

12. Associação entre variáveis

  • Duas qualitativas: tabelas de contingência.
  • Duas quantitativas: dispersão e correlação.
  • Uma qualitativa e uma quantitativa: comparações entre grupos (médias, medianas e box plots).

Correlação de Pearson varia de −1 a +1: positiva, negativa ou próxima de zero (pouca associação linear). Correlação não demonstra causalidade.

Exercício resolvido: 3, 5, 5, 7, 10 → média 6; mediana 5; moda 5; amplitude 7.

Orange Data Mining

1. O que é e como funciona

O Orange Data Mining, desenvolvido na Universidade de Ljubljana, é uma ferramenta visual para análise, mineração de dados e machine learning. O Canvas é a área de montagem; os widgets realizam tarefas; as conexões transportam objetos/dados; e o workflow define a sequência de operações.

O Orange oferece exploração interativa, sugestões de conexões e visualizações, e extensões (add-ons) para funcionalidades adicionais, inclusive mineração de texto, redes e associação.

2. Etapas do fluxo

EntradaAmostragemVisualizaçãoPré-processamentoModeloAvaliaçãoAplicação

3. Entrada de dados e papel das variáveis

WidgetFunção
FileCarrega arquivo e permite configurar colunas
CSV File ImportImporta CSV com configurações de separador/codificação
DatasetsExemplos ou conjuntos de dados disponíveis
SQL TableCarrega dados de bancos compatíveis
Select ColumnsSeleciona e atribui papéis às colunas
FormulaCria atributos derivados por expressões

Feature é entrada para o modelo; Target é o valor a prever; Meta é informação auxiliar, como o nome do aluno. Tipo (numérico, categórico, texto, data/hora) não é o mesmo que papel.

4. Visualização e seleção

Data Table: mostra dados em tabela. Feature Statistics: estatísticas descritivas dos atributos. Rank: avalia e ordena atributos por medidas de relevância. Rank não demonstra causalidade.

5. Select Rows e Data Sampler

Select Rows filtra por condições: idade ≥ 18. Data Sampler amostra registros, podendo usar proporção fixa, quantidade fixa, amostragem com reposição, estratificada, replicável, bootstrap ou partições para validação. With Replacement permite repetir um registro. Stratified busca manter proporções de classes.

6. Discretize: números → categorias

Discretizar é converter variáveis quantitativas em faixas. Por exemplo, 18 e 25 anos na faixa 18–29. Os métodos apresentados incluem: Keep Numeric, Remove, Natural Binning, Fixed Width, Time Interval, Equal Frequency, Equal Width, Entropy-MDL, Custom e Use Default Setting.

Equal Width: intervalos de mesma largura numérica, com quantidades possivelmente diferentes de registros.
Equal Frequency: intervalos com quantidades semelhantes de registros e larguras possivelmente diferentes.
Entropy-MDL: divisões usando um critério de informação, considerando a classe no contexto supervisionado.

7. Continuize: categorias → números

Converte categorias em formatos adequados ao aprendizado. O one-hot encoding cria colunas indicadoras binárias. Outras opções dos slides são Keep Categorical, First Value as Base, Most Frequent Value as Base, Remove If More Than 2 Values, Remove, Treat as Ordinal e Treat as Normalized Ordinal.

Exemplo: cor azul → [1, 0, 0]; verde → [0, 1, 0]; vermelho → [0, 0, 1]. Não crie ordem artificial entre categorias nominais sem justificativa.

8. Normalização e padronização

Min-Max: escala os valores para um intervalo (frequentemente 0–1). Z-score: subtrai a média e divide pelo desvio padrão, de modo que o valor representa desvios padrão em relação à média.

Min-Max: x' = (x − mínimo) / (máximo − mínimo)
Z-score: z = (x − μ) / σ

Exemplos: para valores entre 10 e 30, 20 normalizado é 0,5. Se média 70 e desvio 10, o valor 80 tem z = 1.

9. Seleção de atributos e redução de dimensionalidade

Feature Selection mantém os atributos considerados úteis. RFE remove progressivamente atributos menos importantes segundo um critério. PCA cria componentes novas combinando as variáveis originais e buscando preservar sua variabilidade. CUR utiliza subconjuntos de linhas e colunas para aproximar uma matriz.

O widget Preprocess reúne discretização, continuização, normalização, seleção/redução e outras etapas. Evite overfitting (aprendizado excessivo dos dados de treino) e vazamento de dados (usar informações do teste indevidamente durante preparação/treinamento).

11. Regressão logística, árvore e KNN

Regressão logística: geralmente usada para classificação, frequentemente binária, com probabilidades estimadas por uma função sigmoide. Árvore de decisão: toma decisões dividindo registros por regras sucessivas, como “nota ≥ 7?”. KNN: utiliza os K vizinhos mais próximos; é sensível à escala dos atributos.

12. Test and Score: avaliação

O Test and Score recebe dados e modelos/learners, testa-os e permite comparar métricas. Métodos dos slides: Cross Validation (K partes; cada parte valida uma rodada), Cross Validation by Feature (divisão por atributo), Random Sampling, Leave-One-Out (uma observação por rodada), Test on Train Data (pode superestimar desempenho) e Test on Test Data (dados separados).

13. Matriz de confusão

Suponha um sistema de identificação de fraude:

Fraude realNão fraude real
Previsto: fraudeVP = 40FP = 10
Previsto: não fraudeFN = 20VN = 130
  • VP: positivo identificado corretamente.
  • VN: negativo identificado corretamente.
  • FP: falso alarme de positivo.
  • FN: positivo real não detectado.

14. Métricas de classificação

MétricaFórmula / interpretaçãoExemplo
Accuracy / CA(VP+VN)/(VP+VN+FP+FN)85%
PrecisionVP/(VP+FP): dos positivos previstos, quantos eram reais?80%
RecallVP/(VP+FN): dos positivos reais, quantos foram encontrados?66,7%
F12×(Precision×Recall)/(Precision+Recall)72,7%
AUCÁrea sob curva ROC; discriminação entre classesPróximo de 1 é melhor
MCCCoeficiente que considera VP, VN, FP e FNVaria de −1 a +1

Com classes desbalanceadas, acurácia pode enganar: um modelo que prevê sempre “não fraude” pode acertar 99% se fraude representa só 1% dos casos, mas não detectar fraude alguma.

ROC Analysis: compara taxa de verdadeiros positivos e falsos positivos em diferentes limiares. Lift Curve: mostra o ganho ao concentrar positivos previstos em comparação a uma referência aleatória.

15. Métricas de regressão

MétricaSignificado

RMSERaiz do MSE, mesma unidade do alvo
MAEMédia dos erros absolutos

Com valores reais 10, 20, 30 e previsões 12, 18, 33: MAE ≈ 2,33; MSE ≈ 5,67; RMSE ≈ 2,38.

16. Predictions: aplicação

Depois de treinar e avaliar, o widget Predictions utiliza o modelo para fazer previsões em novos dados e, conforme o problema, mostrar probabilidades de classes.

17. Exemplo completo de workflow

  1. File: carregar planilha de estudantes.
  2. Select Columns: definir Aprovado como Target e horas de estudo/frequência como Features.
  3. Data Table e Feature Statistics: investigar qualidade e distribuição.
  4. Select Rows ou Data Sampler: selecionar registros.
  5. Preprocess: preparar tipos e escalas.
  6. Logistic Regression, Tree e KNN: construir learners.
  7. Test and Score: aplicar validação cruzada.
  8. Confusion Matrix: interpretar erros e acertos.
  9. Predictions: prever aprovação para novos casos.
Memorize: classificação prevê categorias; regressão prevê números; clusterização encontra grupos; associação encontra coocorrências; detecção de outliers encontra anomalias.
